Kebijakan Privasi / Privacy Policy

Berlaku sejak 26 November 2026

Siapa yang memakai aplikasi ini

Aplikasi "insightfinansial poster" hanya digunakan oleh pemilik akun TikTok @insightfinansial untuk mengunggah video miliknya sendiri. Tidak ada pengguna lain.

Data yang diakses

  • Token akses OAuth TikTok dengan izin user.info.basic dan video.upload, diberikan oleh pemilik akun.
  • File video dan teks caption yang dibuat oleh pemilik akun.

Penyimpanan

Token disimpan terenkripsi sebagai GitHub Actions secrets di repositori milik pemilik akun, dan hanya dipakai untuk mengunggah video ke inbox TikTok pemilik akun. Tidak ada data yang dijual, dibagikan, atau digunakan untuk iklan.

Penghapusan

Pemilik akun dapat mencabut akses kapan saja melalui pengaturan TikTok (Keamanan → Aplikasi dan layanan) dan menghapus secrets dari repositori.

English summary

This app is used only by the owner of the TikTok account @insightfinansial to upload the owner's own videos to the owner's TikTok inbox. It stores only the OAuth tokens (scopes user.info.basic, video.upload) as encrypted GitHub Actions secrets in the owner's repository. No data is sold, shared or used for advertising. Access can be revoked at any time in TikTok settings.
